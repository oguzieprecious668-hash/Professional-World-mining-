# ProfessionalMining — educational interface mockup

This repository contains a **static design and education mockup**, not a financial service. The main page has been simplified and account/financial calls to action removed.

## What this site does

- Presents general digital-asset and security education concepts.
- Demonstrates a responsive portfolio-style interface design.
- Labels the site as an educational mockup.

## What it does not do

- Create accounts, accept credentials, or provide a private admin panel.
- Collect personal information, KYC details, or identity documents.
- Connect wallets, hold funds, accept deposits, process withdrawals, or make trades.
- Offer paid investment plans, claim returns, or show real balances/performance.

Do not enter or email passwords, authentication codes, identity documents, payment data, or wallet recovery phrases. All examples are illustrative, not live data or advice.

## Future production work

A legitimate service would require qualified legal/compliance review, independent security assessment, and selection of appropriate regulated identity and financial providers before any customer onboarding or financial feature is designed. See [`docs/FUTURE-PRODUCTION-ARCHITECTURE.md`](docs/FUTURE-PRODUCTION-ARCHITECTURE.md) for a planning document. The separate `production-starter/` folder is a dev-only technical scaffold, not deployed or approved for production use.

## Static preview

The root HTML pages can be previewed with any static file server. GitHub Pages may host this public mockup; it cannot provide protected routes or a trusted backend.
