# Production starter notes

This repository currently hosts a static interface demo only. See [`docs/PRODUCTION-STARTER.md`](docs/PRODUCTION-STARTER.md) for the production architecture, safety boundaries, and readiness gates.

**Do not use the current demo for real accounts, admin access, KYC documents, deposits, withdrawals, investment plans, or profit claims.** There is no backend or secure authentication in this repo. GitHub Pages cannot host a private admin panel or backend service.
